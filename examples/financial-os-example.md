# Example: Financial OS

## Contexto

Financial OS es un producto de referencia para registrar eventos financieros, tarjetas, bancos, deudas, objetivos y proyecciones.

Puede funcionar como app personal, PWA mobile-first y futura plataforma B2B/white-label.

## Módulos aplicados

- `company/`: filosofía de producto sostenible.
- `product/`: discovery, MVP, usuarios, historias y métricas.
- `engineering/`: arquitectura, dominio, casos de uso, ADR.
- `quality/`: estrategia de testing, automatización, datos y métricas.
- `ai/`: input asistido por texto/voz, clasificación y recomendaciones.
- `operations/`: releases, ambientes, secretos y monitoreo.
- `templates/`: PRD, ADR, test strategy, release checklist.
- `starter-kits/`: software product y SaaS monorepo.

## MVP posible

- Registro manual de gastos/ingresos.
- Clasificación básica.
- Tarjetas y bancos.
- Objetivos financieros.
- Dashboard simple.
- Responsive/PWA.
- API backend.
- Persistencia en base de datos.
- Tests API y smoke UI.

## Riesgos

- Scope demasiado amplio.
- Datos financieros sensibles.
- Clasificación incorrecta.
- Falta de hábito del usuario.
- Dependencia prematura de IA.
- Seguridad y privacidad.

## Métricas

- Eventos registrados por semana.
- Retención.
- Tiempo de carga de gasto.
- Categorías corregidas manualmente.
- Objetivos creados.
- Uso mobile.
- Defect leakage.
