# Example: AI Agent

## Contexto

Agente interno para asistir documentación, análisis de issues o generación de casos de prueba.

## Módulos aplicados

- `ai/`
- `quality/`
- `engineering/`
- `operations/`
- `templates/ai/`

## Agent Spec mínimo

- Objetivo claro.
- Tools permitidas.
- Datos permitidos.
- Datos prohibidos.
- Evaluación.
- Logs.
- Owner humano.
- Human-in-the-loop para decisiones críticas.

## Riesgos

- Respuestas incorrectas.
- Uso de datos sensibles.
- Tool misuse.
- Costos no controlados.
- Falta de evaluación.
- Dependencia excesiva.

## Evaluación

- Exactitud.
- Grounding.
- Formato.
- Seguridad.
- Utilidad.
- Consistencia.
