# Evaluation

## Objetivo

Definir cómo evaluar resultados de IA.

## Qué evaluar

- exactitud;
- completitud;
- consistencia;
- utilidad;
- seguridad;
- grounding;
- formato;
- trazabilidad;
- costo;
- latencia;
- robustez;
- manejo de incertidumbre.

## Métodos

- revisión humana;
- datasets de evaluación;
- golden answers;
- comparación entre modelos;
- tests automatizados;
- evaluación por criterios;
- red teaming;
- pruebas de regresión de prompts.

## Regla

Toda capacidad de IA usada de forma repetible debe tener algún mecanismo de evaluación.
