# Tool Use

## Objetivo

Definir cómo una IA puede usar herramientas externas de forma controlada.

## Herramientas posibles

- repositorios;
- documentación;
- APIs;
- bases de datos;
- navegadores;
- sistemas de tickets;
- calendarios;
- email;
- storage;
- pipelines;
- test runners.

## Reglas

- Cada herramienta debe tener propósito claro.
- El agente debe usar la herramienta mínima necesaria.
- Toda acción destructiva requiere confirmación humana.
- Los accesos deben respetar permisos.
- Los resultados deben registrarse cuando impactan decisiones.

## Regla

Una IA con herramientas es más poderosa y más riesgosa.

El diseño debe reflejar ese riesgo.
