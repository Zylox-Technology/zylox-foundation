# Safety and Security

## Objetivo

Definir controles mínimos de seguridad para uso de IA.

## Riesgos

- exposición de datos sensibles;
- prompt injection;
- tool misuse;
- respuestas peligrosas;
- fuga de información;
- acceso indebido;
- generación de código inseguro;
- dependencia excesiva;
- acciones automáticas no autorizadas.

## Reglas mínimas

- No enviar secretos.
- No enviar datos personales sensibles sin autorización.
- No ejecutar acciones destructivas sin confirmación.
- No copiar código generado sin revisión.
- No exponer información interna innecesaria.
- Validar outputs que impacten usuarios, dinero, seguridad o datos.
