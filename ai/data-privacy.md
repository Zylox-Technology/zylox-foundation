# Data Privacy

## Objetivo

Definir cómo proteger datos cuando se usa IA.

## Datos sensibles

- credenciales;
- tokens;
- claves API;
- información personal;
- información financiera;
- datos de clientes;
- contratos;
- documentación confidencial;
- código privado;
- incidentes de seguridad.

## Reglas

- Minimizar datos enviados.
- Anonimizar cuando sea posible.
- Usar proveedores aprobados.
- Revisar términos de uso.
- Evitar entrenamiento no autorizado con datos internos.
- Registrar excepciones.

## Regla

Si no sabemos si un dato puede compartirse, no se comparte.
