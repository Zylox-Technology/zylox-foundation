# Context Engineering

## Objetivo

Diseñar el contexto que una IA necesita para producir resultados útiles, consistentes y seguros.

## Componentes de contexto

- objetivo;
- rol esperado;
- reglas;
- restricciones;
- documentos fuente;
- ejemplos;
- definiciones;
- criterios de aceptación;
- formato de salida;
- errores comunes;
- información prohibida;
- límites de decisión.

## Buen contexto

Un buen contexto:

- reduce ambigüedad;
- evita repetir instrucciones;
- baja riesgo de alucinación;
- mejora consistencia;
- facilita evaluación;
- protege información sensible.

## Regla

Un prompt aislado no es estrategia de IA.

El contexto debe diseñarse como parte del sistema.
