# Test Strategy

Una estrategia de test debe incluir:

- alcance;
- fuera de alcance;
- riesgos;
- tipos de prueba;
- niveles de prueba;
- ambientes;
- datos;
- herramientas;
- responsables;
- criterios de entrada;
- criterios de salida;
- métricas;
- evidencia esperada.

No existe una estrategia universal. Se diseña según producto, riesgo, contexto y madurez del equipo.
