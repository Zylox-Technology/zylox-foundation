# Performance Testing

Evaluar cómo se comporta el sistema bajo carga, estrés, volumen y uso sostenido.

## Tipos

- Load testing.
- Stress testing.
- Spike testing.
- Soak testing.
- Capacity testing.
- Baseline testing.

## Métricas

Response time, throughput, error rate, CPU, memory, database usage, queue latency, P95/P99 y saturación.
