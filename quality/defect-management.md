# Defect Management

Un defecto debe incluir:

- título claro;
- ambiente;
- versión;
- pasos para reproducir;
- resultado actual;
- resultado esperado;
- evidencia;
- severidad;
- prioridad;
- impacto;
- datos usados;
- frecuencia;
- posible causa si se conoce.

Severidad describe impacto técnico o funcional. Prioridad describe urgencia de negocio.
