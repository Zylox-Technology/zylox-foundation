# UI Testing

Validar experiencia visible, flujos principales e integración desde la perspectiva del usuario.

## Qué validar

- Flujos críticos.
- Navegación.
- Estados vacíos.
- Mensajes de error.
- Validaciones visibles.
- Responsive.
- Accesibilidad básica.
- Estados de carga.

Usar selectores estables y evitar automatizar cada detalle visual.
