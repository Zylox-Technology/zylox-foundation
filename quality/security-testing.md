# Security Testing

Detectar riesgos de seguridad antes de producción.

## Validaciones base

- Autenticación.
- Autorización.
- Validación de entradas.
- Manejo de errores.
- Exposición de datos sensibles.
- Inyección.
- Rate limiting.
- Sesiones.
- Tokens.
- Permisos.
- Dependencias vulnerables.

Referencias: OWASP Top 10 y OWASP API Security Top 10.
