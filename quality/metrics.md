# Quality Metrics

Medimos para decidir, no para decorar dashboards.

## Métricas útiles

- Defect leakage.
- Flaky tests.
- Automation pass rate.
- Test execution time.
- Lead time to fix.
- Escaped defects.
- Coverage por riesgo.
- Build stability.
- Change failure rate.
- Mean time to detect.
- Mean time to recover.

Toda métrica debe responder: ¿qué decisión permite tomar?
