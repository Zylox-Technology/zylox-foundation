# API Testing

Validar contratos, reglas de negocio, errores, seguridad básica y consistencia de datos a nivel API.

## Qué validar

- Status codes.
- Schemas.
- Campos obligatorios.
- Validaciones.
- Errores esperados.
- Permisos.
- Idempotencia.
- Paginación.
- Filtros.
- Límites.
- Efectos secundarios.

Herramientas posibles: Postman/Newman, Pytest + httpx, Robot Framework, Playwright API, Schemathesis.
