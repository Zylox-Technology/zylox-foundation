- Se agregan Roles and Responsibilities.
- Se agrega Automation Tracking.
- Se agrega Quality Metrics Governance.

### Metrics
- Se define que las métricas deben responder qué decisión permiten tomar.
- Se separa medición de QA Testing de medición de Quality Engineering general.

### Automation
- Se define tracking mínimo para casos automatizados.
- Se define seguimiento de flakiness, última ejecución, evidencia y defectos asociados.

### Decision
- Quality se define como disciplina de ingeniería, no como etapa final de testing.
- Quality extiende y complementa Engineering.
