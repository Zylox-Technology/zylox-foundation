# Feedback Loop

## Objetivo

Cerrar el ciclo entre construir, lanzar, medir y aprender.

## Fuentes de feedback

- usuarios;
- clientes;
- soporte;
- métricas;
- analytics;
- defectos;
- incidentes;
- entrevistas;
- ventas;
- equipo interno.

## Salidas posibles

- mantener rumbo;
- ajustar backlog;
- cambiar prioridad;
- redefinir MVP;
- crear nueva hipótesis;
- mejorar calidad;
- descartar una feature.

## Regla

Un producto que no aprende después de liberar está acumulando incertidumbre.
