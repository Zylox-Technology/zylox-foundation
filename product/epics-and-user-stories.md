# Epics and User Stories

## Epic

Una epic agrupa trabajo relacionado a un objetivo de producto.

Debe tener:

- objetivo;
- contexto;
- usuario;
- alcance;
- fuera de alcance;
- riesgos;
- métricas;
- historias asociadas.

## User Story

Formato sugerido:

```text
Como [usuario],
quiero [acción/necesidad],
para [beneficio].
```

## Regla

Una historia sin criterio de aceptación no está lista para desarrollo.
