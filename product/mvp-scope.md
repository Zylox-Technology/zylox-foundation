# MVP Scope

## Objetivo

Definir el alcance mínimo que permite aprender si la solución tiene valor.

MVP no significa producto incompleto. Significa producto enfocado en validar una hipótesis importante.

## Criterios de MVP

Un MVP debe:

- resolver un problema concreto;
- cubrir un usuario o segmento claro;
- tener flujo principal completo;
- medir resultado;
- ser construible en tiempo razonable;
- reducir incertidumbre;
- evitar funcionalidades decorativas.

## Regla

Si todo es MVP, nada es MVP.

## Controlled release vs public release

Un MVP puede estar apto para prueba controlada sin estar apto para publicación pública.

Los criterios deben separarse explícitamente:

- local testing;
- controlled/internal testing;
- closed testing;
- public release;
- marketplace/store release.

No mezclar aceptación de riesgo controlado con readiness pública.
