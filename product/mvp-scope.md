# MVP Scope

## Objetivo

Definir el alcance mínimo que permite aprender si la solución tiene valor.

MVP no significa producto incompleto. Significa producto enfocado en validar una hipótesis importante.

## Criterios de MVP

Un MVP debe:

- resolver un problema concreto;
- cubrir un usuario o segmento claro;
- tener flujo principal completo;
- medir resultado;
- ser construible en tiempo razonable;
- reducir incertidumbre;
- evitar funcionalidades decorativas.

## Regla

Si todo es MVP, nada es MVP.
