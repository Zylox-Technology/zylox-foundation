# Problem Framing

## Objetivo

Definir el problema de forma clara, específica y accionable.

## Formato recomendado

```text
Para [usuario/segmento],
que necesita [necesidad],
el problema es [problema],
porque [causa/impacto],
y hoy se resuelve mediante [alternativa actual].
```

## Buen problema

Un buen problema:

- identifica usuario;
- describe dolor real;
- evita asumir solución;
- explica impacto;
- permite definir hipótesis;
- puede validarse.

## Regla

Si el problema ya contiene la solución, probablemente está mal formulado.
