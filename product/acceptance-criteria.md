# Acceptance Criteria

## Objetivo

Definir cómo sabemos si una historia, feature o flujo cumple lo esperado.

## Formato Given / When / Then

```gherkin
Given [contexto]
When [acción]
Then [resultado esperado]
```

## Incluir

- happy path;
- errores;
- validaciones;
- permisos;
- estados límite;
- mensajes relevantes;
- reglas de negocio;
- impacto en datos.

## Regla

Si no se puede validar, no es criterio de aceptación.
