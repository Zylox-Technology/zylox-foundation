# User Journeys

## Objetivo

Mapear cómo un usuario atraviesa un proceso antes, durante y después de usar el producto.

## Elementos

- Etapas.
- Acciones.
- Pensamientos.
- Dolores.
- Canales.
- Datos necesarios.
- Riesgos.
- Oportunidades.
- Momentos críticos.

## Uso

Los journeys sirven para detectar fricciones, definir MVP, descubrir automatizaciones, identificar riesgos, escribir historias, diseñar pruebas end-to-end y priorizar flujos críticos.
