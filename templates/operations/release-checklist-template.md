# Release Checklist

## Release

Version / Name

## Pre-release

- [ ] Scope confirmed.
- [ ] Changelog updated.
- [ ] VERSION updated.
- [ ] Tests critical passed.
- [ ] Quality report reviewed.
- [ ] Security checks reviewed.
- [ ] Rollback plan defined.
- [ ] Owners available.
- [ ] Release notes prepared.

## Deploy

- [ ] Deployment started.
- [ ] Deployment completed.
- [ ] Smoke tests executed.
- [ ] Monitoring checked.
- [ ] Logs checked.

## Post-release

- [ ] Product metrics monitored.
- [ ] Support informed.
- [ ] Incident channel ready if needed.
- [ ] Release communicated.
- [ ] Lessons learned captured.
