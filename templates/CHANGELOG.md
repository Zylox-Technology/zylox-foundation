# Templates Changelog

Todas las modificaciones relevantes del módulo Templates deben registrarse en este archivo.

## [0.1.0] - 2026-07-02

### Added
- Se crea el módulo Templates.
- Se agregan templates de Architecture: ADR y RFC.
- Se agregan templates de Product: Discovery Brief, PRD, MVP Scope, Epic y User Story.
- Se agregan templates de Quality: Test Strategy, Test Case, Bug Report, Quality Report, Automation Tracking y Quality Metrics.
- Se agregan templates de Operations: Release Notes, Release Checklist, Incident Report, Runbook y Change Request.
- Se agregan templates de AI: Prompt, Agent Spec y Evaluation.
- Se agrega template de GitHub Pull Request.

### Decision
- Templates se define como el módulo que convierte los estándares de Zylox Foundation en artefactos aplicables.
