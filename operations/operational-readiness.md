# Operational Readiness

## Objetivo

Determinar si una solución está lista para operar.

## Checklist

- Documentación de setup.
- Variables de entorno documentadas.
- Secretos gestionados.
- Pipeline funcionando.
- Ambientes definidos.
- Logs mínimos.
- Métricas críticas.
- Alertas necesarias.
- Runbook básico.
- Owner definido.
- Estrategia de rollback.
- Quality gates.
- Seguridad mínima.
- Backups si aplica.
- Soporte definido.
- Perfil de infraestructura y restricciones conocidas.
- Evidencia de alineación entre versión de app, esquema de datos y smoke runtime.

## Regla

Si nadie sabe cómo operar una solución, la solución no está lista.
