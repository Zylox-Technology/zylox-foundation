# Repository Governance

## Objetivo

Definir reglas mínimas para repositorios de Zylox.

## Repositorios deben tener

- README;
- VERSION cuando aplique;
- CHANGELOG;
- .gitignore;
- estrategia de ramas;
- owners;
- PR template;
- issue templates cuando aplique;
- branch protection;
- reglas de review;
- documentación mínima de setup;
- criterios de release.

## Owners

Cada repositorio debe tener responsables claros.

Tipos de ownership:

- Product Owner;
- Technical Owner;
- Quality Owner;
- Operations Owner.

En proyectos chicos, una persona puede ocupar más de un rol.

## Regla

Un repo sin owner es deuda operativa.
