# Secrets Management

## Objetivo

Proteger credenciales, tokens, claves y secretos.

## Secretos

- API keys;
- tokens;
- passwords;
- connection strings;
- private keys;
- certificados;
- webhooks secrets;
- cloud credentials.

## Reglas

- Nunca subir secretos al repo.
- Nunca compartir secretos por chat.
- Usar secret managers o variables seguras.
- Rotar secretos comprometidos.
- Separar secretos por ambiente.
- Limitar acceso.
- Registrar owner.

## Regla

Un secreto expuesto debe tratarse como comprometido.
