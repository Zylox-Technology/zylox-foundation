# Runbooks

## Objetivo

Documentar cómo ejecutar o recuperar operaciones frecuentes o críticas.

## Un runbook debe incluir

- objetivo;
- cuándo usarlo;
- prerequisitos;
- pasos;
- comandos si aplica;
- validaciones;
- rollback;
- errores frecuentes;
- owner;
- última revisión.

## Runbooks recomendados

- deploy;
- rollback;
- restaurar backup;
- rotar secreto;
- levantar ambiente;
- ejecutar migración;
- responder incidente;
- regenerar artefactos;
- correr suite crítica;
- publicar release.

## Regla

Si una operación es crítica y depende de memoria humana, necesita runbook.
