# Support Process

## Objetivo

Definir cómo se reciben, clasifican, priorizan y resuelven pedidos o problemas operativos.

## Tipos de soporte

- bug funcional;
- incidente;
- consulta;
- mejora;
- problema de acceso;
- problema de datos;
- problema de performance;
- problema de integración.

## Campos mínimos

- solicitante;
- fecha;
- descripción;
- ambiente;
- prioridad;
- impacto;
- evidencia;
- owner;
- estado;
- resolución;
- acción preventiva si aplica.

## Regla

Soporte sin clasificación termina mezclando urgencia, ruido y deuda.
