# Project Context

## Proyecto

Zylox Foundation

## Repositorio

`zylox-foundation`

## Organización

Zylox Technology

## Propósito

Crear un framework base para definir cómo Zylox diseña, construye, valida, opera y evoluciona soluciones de ingeniería.

## Filosofía

Zylox no se define por una herramienta, lenguaje, framework, IA o proveedor.

Zylox se define por una forma de pensar, diseñar, construir, validar, operar y evolucionar soluciones.

## Frases rectoras

> Technology changes. Engineering endures.

> Good engineering outlives technology.

> Engineering sustainable solutions for evolving problems.

## Estilo de trabajo elegido

El usuario pidió evitar roadmaps eternos y avanzar con entregables concretos.

Metodología acordada:

1. Diseñar módulo.
2. Generar ZIP/patch.
3. Subir al repo.
4. Iterar.
5. Mantener README, CHANGELOG y VERSION actualizados.
