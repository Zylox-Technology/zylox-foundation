# Knowledge Base

El módulo Knowledge Base contiene una versión comprimida y reutilizable del contexto de Zylox Foundation.

Sirve para:

- continuar el trabajo en otro chat;
- dar contexto a una IA;
- hacer onboarding;
- explicar decisiones tomadas;
- evitar perder continuidad;
- documentar el estado actual del framework.

## Documentos incluidos

- `project-context.md`
- `decisions-log.md`
- `current-state.md`
- `assistant-handoff.md`
- `next-steps.md`
- `CHANGELOG.md`

## Uso recomendado

Antes de continuar el framework en otro entorno:

1. Leer `project-context.md`.
2. Leer `current-state.md`.
3. Leer `decisions-log.md`.
4. Copiar `assistant-handoff.md` como contexto inicial.
5. Usar `next-steps.md` para decidir la próxima evolución.

## Regla

La base de conocimiento debe resumir sin reemplazar la documentación fuente.
