# Internal Tool Starter Kit

## Objetivo

Iniciar una herramienta interna simple sin perder estándares de seguridad, calidad y operación.

## Estructura sugerida

```text
internal-tool/
├── README.md
├── docs/
│   ├── problem.md
│   ├── users.md
│   ├── architecture.md
│   └── operations.md
├── src/
├── tests/
├── scripts/
└── .github/
```

## Documentos mínimos

- Problem framing.
- User story.
- Acceptance criteria.
- Architecture note.
- Test strategy mínima.
- Runbook.

## Checklist inicial

- [ ] Usuario interno identificado.
- [ ] Problema definido.
- [ ] Flujo crítico definido.
- [ ] Permisos definidos.
- [ ] Datos sensibles revisados.
- [ ] Testing mínimo definido.
- [ ] Operación básica definida.
