# Software Product Starter Kit

## Objetivo

Iniciar un producto de software alineado a Product, Engineering, Quality, AI y Operations.

## Módulos a revisar

- `company/`
- `product/`
- `engineering/`
- `quality/`
- `operations/`
- `ai/` si aplica
- `templates/`

## Estructura sugerida

```text
product-name/
├── README.md
├── VERSION
├── CHANGELOG.md
├── docs/
│   ├── product/
│   ├── architecture/
│   ├── quality/
│   └── operations/
├── src/
├── tests/
├── scripts/
├── .github/
└── .env.example
```

## Documentos mínimos

- PRD.
- MVP Scope.
- ADR inicial.
- Test Strategy.
- Release Checklist.
- README de setup.
- Definition of Ready.
- Definition of Done.

## Checklist inicial

- [ ] Problema definido.
- [ ] Usuario identificado.
- [ ] MVP definido.
- [ ] Arquitectura inicial documentada.
- [ ] Estrategia de calidad definida.
- [ ] Ambientes definidos.
- [ ] Branch protection definido.
- [ ] Pipeline mínimo definido.
- [ ] Métricas iniciales definidas.
