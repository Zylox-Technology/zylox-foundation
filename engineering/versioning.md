# Versioning

## Principio

Las versiones comunican estabilidad y cambio.

## Convención

Usamos Semantic Versioning cuando aplique.

```text
MAJOR.MINOR.PATCH
```

- MAJOR: cambios incompatibles.
- MINOR: funcionalidades compatibles.
- PATCH: correcciones compatibles.

## Releases internas

Para productos tempranos:

```text
0.1.0
0.2.0
0.3.0
```

Una versión `0.x` indica que el producto aún puede cambiar, pero no habilita desorden.

## Regla

Cada release debe poder explicar qué cambió y por qué.
