# Definition of Ready

Una tarea está lista para desarrollarse cuando:

- El objetivo está claro.
- El alcance está definido.
- Existen criterios de aceptación.
- Se conocen dependencias.
- Se identificaron riesgos principales.
- Se sabe cómo probarla.
- No existen decisiones de arquitectura bloqueantes.

Si una tarea no cumple esto, no está lista.
