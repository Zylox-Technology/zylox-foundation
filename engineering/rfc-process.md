# RFC Process

## Qué es un RFC

Un Request for Comments permite discutir una idea antes de convertirla en decisión.

## Cuándo usar RFC

- Nuevos módulos.
- Cambios grandes de arquitectura.
- Integraciones importantes.
- Cambios en procesos.
- Nuevas herramientas.
- Decisiones con alto impacto.

## Diferencia con ADR

RFC discute.

ADR decide.

Un RFC puede terminar en uno o varios ADR.
