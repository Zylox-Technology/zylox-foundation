# Company

El módulo Company define la identidad institucional de Zylox.

Su objetivo es establecer una base común para la toma de decisiones, el posicionamiento, la cultura y la forma de entender la ingeniería.

## Documentos incluidos

- `core-statements.md`
- `manifesto.md`
- `mission.md`
- `vision.md`
- `values.md`
- `culture.md`
- `positioning.md`
- `engineering-philosophy.md`

## Uso

Este módulo debe revisarse antes de iniciar cualquier proyecto importante de Zylox.

Define cómo pensamos, no solamente qué hacemos.
